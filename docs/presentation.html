Ce que le serveur propose

search_legal_skills

Cherche des compétences. Trois modes : hybride par défaut, mots-clés, ou sens. Filtres par pays, langue, domaine et tag.

get_legal_skill

Renvoie le texte complet d'une compétence et la liste de ses fichiers annexes. Les scripts sont listés, jamais exécutés.

list_legal_facets

Compte les compétences par langue, pays, domaine et tag. Sert à parcourir la bibliothèque avant de chercher.

Comment ça marche

Le mode hybride prend les meilleurs résultats de chaque index, à tour de rôle, sans doublon. Un résultat trouvé par un seul index reste donc visible, même s'il n'est pas dans le top de l'autre.

Trois modes de recherche

ModeCe qu'il retientQuand l'utiliser
hybrid (défaut)Les meilleurs résultats des deux index, alternésUne question en langage courant, dans n'importe quelle langue
keywordLes termes exacts, avec le glossaire de conceptsUn terme précis, un titre, un article de loi
semanticLe sens seulUne formulation éloignée du vocabulaire des compétences

Limites

  • La recherche par sens utilise un modèle léger. Elle remonte parfois des résultats hors sujet, surtout pour une requête vague.
  • Les tags ne couvrent que 3,6 % de la bibliothèque. Le filtre par type de tâche reste donc partiel.
  • Le français est peu représenté, avec 109 compétences sur 20 293. Pour une question française, le filtre par pays et par domaine aide beaucoup.
  • Le glossaire est écrit à la main et couvre 19 concepts.
  • Les résultats ne sont pas un avis juridique. Le projet ne garantit pas la qualité juridique des compétences : vérifiez chaque point auprès des sources officielles.

Installer

git clone --recurse-submodules <url-du-depot>
cd legal-skills-mcp
npm install
npm run build
npm run build:embeddings

La première construction de l'index sémantique télécharge un modèle d'environ 118 Mo et prend une dizaine de minutes. Ensuite, ouvrez le dossier dans Claude Code et approuvez le serveur legal-skills.
